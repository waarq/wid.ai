- **Setup (Sonnet):**
  - 26 shadcn components customized to the WIT look, with warm off-white and tinted near-black, one emerald accent, Geist fonts and small radii.
  - Providers, shared state components (empty, error, loading, confirm, status badge) and a UI store.
  - `docs/design-system.md`.
- **Source layout:** everything lives under `src/`, because the repo already did. The PRD's root-level folder names map to `src/` equivalents.
- **Gitignore fix:** `.gitignore` was ignoring `.env.example`, so I added an exception for it.

## Decisions to review
1. **Required traceability:** every AI insight must carry `sourceSegmentId` and `sourceTimestamp`. The PRD had these optional on `ActionItem`.
2. **Paginated lists:** list methods return `{ items, total, nextCursor }` instead of a bare array, which suits a real backend better.
3. **Duplicate "Ready" status:** the PRD lists "Ready" twice, so the first became `ready_to_capture`.
4. **Session auth:** sessions assume backend httpOnly cookies, and no token is stored on the client.
5. **Next 16 differences:** `middleware` is now `proxy.ts`, and `params` and `searchParams` are Promises. `docs/conventions.md` lists the rest.
